# TOKI desktop assistant

floating windows assistant for accessing window shortcut apps in single touch.

this wont permanently make it there when laptop is turned on so use startup app folder to copy the shortcut of exe and paste there,
Step by step
1. Win+R
2. type shell:startup
3. you see a folder
4. now go to the folder your app exe is and right click it
5. clcik show more options
6. click create shortcut
7. then cut or copy that shortcut and paste it on to the startup folder and boom its ready to use as soon as u open ur laptop or pc
